# Catégories des supports

- Disques durs et supports amovibles : interfaces HDD et lecteurs Zip/Jaz/SyQuest. Le Zip est traité par Windows comme un périphérique de disque amovible dans l’inventaire réel ; il n’est pas classé parmi les lecteurs de bandes.
- Bandes et cassettes audio : acquisition via les entrées audio.
- Bandes de données : lecteurs de bandes de sauvegarde, par exemple LTO. [IBM décrit les cartouches LTO comme contenant une bande magnétique](https://www.ibm.com/docs/en/ts4300-tape-library?topic=overview-supported-tape-cartridges).

Classification rappelée et référence consultée le 14 novembre 2026. Ne pas déplacer Zip/Jaz/SyQuest dans les bandes de données.
