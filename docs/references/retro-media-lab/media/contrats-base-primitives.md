`BytePrimitives.h` est le point commun de l’inversion des bits et de l’écriture little endian 24 bits. Les deux bibliothèques utilisent la même fonction inline ; aucun appel de DLL n’est ajouté dans ces traitements. Les consommateurs VOC et Amstrad reprennent maintenant ce helper comme dans le C#. ADFS et ProDOS l’utilisent par l’alias Binary existant.

La compilation générale Debug a réussi. Le contrôle ciblé a confirmé l’identité du helper entre les espaces de noms, l’inversion des 256 octets possibles, la sortie 24 bits et le refus sans modification d’une destination courte. Il n’a exécuté aucun codec ni utilisé de média. Son répertoire a été supprimé.

Le seul consommateur C# de ByteListCopy est le lecteur de répertoire Commodore ; son équivalent natif transmet directement une sous-plage bornée à PETSCII. Les anciennes directives GlobalUsings ne portent aucun comportement runtime et deviennent des inclusions de types explicites.
