# Rapprochement des constantes de chaînes

Les déclarations de chaînes du C# sont résolues par leur espace de noms, leur classe réelle (y compris les classes partielles), leurs alias et leurs déclarations multiples. Chaque valeur doit correspondre à une constante nommée native. Ces fichiers ne contiennent aucune méthode de calcul. Ce contrôle ne reteste pas les lecteurs ou codecs.
